**Job Description**
We are looking for Rust Engineers who have a strong interest in systems engineering, low-level architecture, high-performance services, and distributed systems. You will participate in the design and development of core infrastructure, trading systems, blockchain components, or high-performance backend services.
We expect you to not only write code but also possess a solid foundation in computer science, with a deep understanding of system behavior, performance bottlenecks, network protocols, concurrency models, and engineering quality.
⸻

**Responsibilities**
* Develop high-performance, highly reliable backend services and infrastructure components using Rust.
* Design architectures for distributed systems, network services, middleware, or trading systems.
* Optimize system performance, latency, memory utilization, and overall stability.
* Implement core modules featuring concurrent, asynchronous, and message-driven architectures.
* Write high-quality, maintainable, and testable production code.
* Troubleshoot production issues, perform system tuning, and build disaster recovery mechanisms.
⸻

**Requirements**
Hard Requirements
* Proficiency in the Rust language with hands-on project development experience.
* Solid computer science foundation, including but not limited to:
    * Operating Systems
    * Computer Networks
    * Data Structures &amp; Algorithms
    * Concurrency / Parallelism
    * Databases &amp; Storage
    * Distributed Systems Fundamentals
    * Cryptography Fundamentals
* Familiarity with Linux development environments.
* Strong engineering capabilities and a high awareness of code quality.
* Keen interest in performance optimization, system design, and low-level principles.
* Excellent problem-analysis and problem-solving skills.

Plus Factors (Preferred Qualifications)
Experience in any of the following directions is a plus:
* Blockchain / Web3 / ZK / Consensus Protocols development experience.
* CEX / DEX / Matching Engines / Orderbook / High-Frequency Trading (HFT) systems development experience.
* Distributed storage, messaging systems, or stream processing systems experience.
* Deep understanding of Tokio, async runtimes, lock-free programming, or network stacks.
* Hands-on experience with infrastructure like RocksDB, Kafka, NATS, Redis, or PostgreSQL.
* Familiarity with protocols such as TCP/UDP, WebSocket, FIX, or RPC.
* Proven track record in optimizing high-concurrency, low-latency systems.
* Contributions to open-source projects.
⸻

**What We Look For**
* Long-term passion for technology.
* Eagerness to understand underlying system principles rather than staying at the framework level.
* High standards for code quality and architectural design.
* Ability to think independently and drive problem-solving.
