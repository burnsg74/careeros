ArcheSys is a technology firm specializing in innovative cloud solutions and services for clients across various industries. We pride ourselves on our cutting-edge technologies, exceptional customer service, and collaborative work environment.  

We are seeking a seasoned Software Engineer with a strong background in building front end applications using .NET solutions in Azure cloud services. The successful candidate will be part of our team driving the transformation of enterprise applications, focusing on robust, scalable solutions. With a strong emphasis on collaboration, innovation, and continuous improvement, you'll be at the forefront of ensuring the delivery of top-tier solutions for our customers.

This is a fully remote, full-time position.

**Key Responsibilities**
* **Frontend Architecture &amp; Integration:** Design, build, and optimize high-performance web applications, focusing deeply on integrating modern React and Next.js interfaces with Core MVC ASP.NET backends.
* **Modern Web Development:** Develop scalable user-facing features, components, and server-side or statically rendered views that unify the Microsoft web stack with modern JavaScript ecosystems.
* **Accessibility &amp; Styling:** Create responsive, highly styled layouts using advanced CSS, ensuring all user interfaces adhere strictly to web accessibility standards (ARIA, semantic HTML, and compliance guidelines).
* **AI-Assisted Delivery:** Embrace and leverage Agentic AI-assisted development platforms to accelerate component design, automate code refactoring, and maintain rapid engineering velocity without compromising code quality.
* **Secure Auth Systems:** Collaborate with cloud and backend engineers to implement tight application-level security, secure routing, and end-to-end authentication/authorization patterns (Security/Auth).
* **Cloud App Optimization:** Identify UI performance bottlenecks and optimize state management, rendering, and API data-flow patterns within Azure cloud environments.
