**Location:** Remote (United States)  

**Salary:** $95,000–$110,000 per year 

## About the Role

**Zorqiva** is a technology consulting and software engineering company headquartered in Hong Kong and Anchorage, Alaska. We partner with startups, scale-ups, and enterprise clients to build modern web applications, cloud solutions, AI-powered products, and custom software. Our distributed teams collaborate across time zones to deliver high-quality solutions for clients worldwide.

We are looking for a Senior Django Developer to join our growing engineering team. This role is ideal for an experienced backend engineer with strong expertise in Python, Django, Django REST Framework, relational databases, and scalable application architecture.

You will take ownership of backend systems, contribute to architectural and technical decisions, mentor other engineers, and work directly with U.S.-based clients while collaborating closely with our engineering team in Hong Kong. We are looking for someone who is technically strong, detail-oriented, comfortable solving complex engineering problems, and able to balance software quality, performance, maintainability, security, and business requirements.

This is a remote position for candidates currently located in the United States.

## What You’ll Do

- Design, develop, and maintain backend applications using Python and Django.
- Build secure, scalable, reusable services, APIs, and application components.
- Design, implement, document, and maintain REST APIs using Django REST Framework.
- Write clean, efficient, testable, and maintainable Python code.
- Design data models and optimize database access using the Django ORM.
- Work with relational databases, including PostgreSQL, MySQL, or similar systems.
- Diagnose and resolve application, API, database, reliability, and performance issues.
- Contribute to system architecture and make sound technical design decisions.
- Review code and help establish engineering standards, best practices, and documentation.
- Mentor junior and mid-level engineers through code reviews, pairing, and technical guidance.
- Collaborate with frontend engineers, product managers, designers, clients, and other stakeholders.
- Write and maintain unit, integration, and API tests to support quality and reliability.
- Troubleshoot applications across development, testing, staging, and production environments.
- Improve application performance, scalability, observability, security, and reliability.
- Contribute to CI/CD workflows, deployment processes, and engineering documentation.
