We’re hiring a Senior Full-Stack Engineer to help build and scale our AI-platform used directly by customers to solve real operational problems. You’ll work across frontend, backend, and AI systems, owning features from idea to production in a small, fast-moving team. This role is ideal for engineers who enjoy end-to-end ownership, systems thinking, and building production AI applications.

**Why this role**
* Work directly with company leadership on core product development
* Small, high-trust engineering team with fast iteration and minimal process overhead
* Opportunity to shape how production AI systems are designed, deployed, and scaled

**What you’ll do**
* Build end-to-end product features across frontend (React / Next.js) and backend (FastAPI or similar)
* Design and operate production LLM systems, including agent workflows and structured prompting
* Build retrieval systems powering LLM features (embeddings, RAG architectures)
* Own infrastructure components including deployments, CI/CD, containerized services, and production configuration
* Design and maintain secure multi-tenant APIs with authentication and authorization
* Improve system reliability, observability, and performance as the platform scales

**What we’re looking for**
* Professional software engineering experience or equivalent experience building production AI systems
* Ability to own features end-to-end, from backend APIs through frontend integration
* Backend experience in Python (FastAPI or similar) including async I/O and API design
* Experience working with relational databases
* Ability to write clean, maintainable, well-tested code in a collaborative environment
* Clean architecture or domain-driven design patterns
* Strong engineering practices (testing, CI quality gates, Git workflows)
* Experience with LLM platforms and orchestration frameworks (OpenAI, Anthropic, LangGraph, LangChain or equivalents)
* Experience with RAG pipelines, embedding search, and data ingestion workflows
* Frontend experience in React / Next.js / TypeScript
* Experience operating production infrastructure (deployments, CI/CD, containerized services)

**How you work**
* Demonstrated technical ownership and decision-making
* Bias toward action in ambiguous problem spaces
* Strong written communication for documentation and code reviews
* Comfortable working in remote, fast-iteration environments
