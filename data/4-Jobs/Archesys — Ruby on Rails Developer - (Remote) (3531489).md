ArcheSys is a technology consulting firm delivering innovative cloud, AI, DevSecOps, and digital modernization solutions to Federal, State, and Commercial customers. We help organizations accelerate mission outcomes through secure software development, cloud-native engineering, accessibility, and intelligent automation.

We are seeking a highly skilled and motivated Ruby on Rails Developer to join our growing engineering team. In this role, you will design, develop, and maintain modern web applications that support high-impact public sector initiatives. You'll collaborate closely with product managers, UX designers, architects, and fellow engineers in an Agile environment to deliver secure, scalable, and accessible digital services.

The ideal candidate thrives in a collaborative, fast-paced environment and enjoys building high-quality software while leveraging modern AI-assisted development tools to improve productivity, code quality, and delivery speed.

This is a fully remote, full-time position.

**Residency Requirement**
Candidates MUST have lived in the U.S. for at least 3 of the past 5 years and be authorized to work in the U.S. (U.S. Citizen, Permanent Resident, or EAD).

**Sponsorship**
This position does not offer sponsorship. Candidates must already be authorized to work in the United States.

**Clearance**
Public Trust Clearance (or the ability to obtain one) may be required depending on the assigned project.


### **Roles and Responsibilities

**Full-Stack Application Development**
* Design, develop, and maintain Ruby on Rails applications supporting mission-critical government and commercial systems.
* Develop responsive, accessible, and user-friendly interfaces using ERB templates, HTML5, JavaScript, and modern CSS.
* Build and maintain critical user workflows including forms, dashboards, reporting, user authentication, and role-based access management.
* Design and develop secure RESTful APIs and integrate with external systems and cloud services.
* Write clean, maintainable, reusable, and well-tested code following software engineering best practices.

**Frontend Engineering**
* Develop responsive user interfaces using modern JavaScript, CSS, and browser-native Web Components.
* Contribute to shared UI components and design systems.
* Support implementation of Maryland Web Design System (MDWDS), U.S. Web Design System (USWDS), or similar government design systems.
* Ensure applications meet WCAG 2.1 AA accessibility standards and responsive design best practices.

**AI-Assisted Software Development**
* Leverage AI development tools such as GitHub Copilot, ChatGPT, OpenAI, Amazon Q Developer, Claude, Cursor, or similar tools to improve engineering productivity.
* Use AI responsibly to accelerate code generation, documentation, unit testing, debugging, refactoring, and code reviews.
* Apply human judgment to validate AI-generated code for correctness, security, maintainability, accessibility, and compliance.
* Utilize AI tools to generate technical documentation, test cases, API specifications, and implementation guidance.
* Stay current on emerging AI software engineering practices and recommend improvements to development workflows.

**Collaboration &amp; Technical Leadership**
* Collaborate closely with product managers, UX designers, solution architects, and fellow engineers to translate business requirements into technical solutions.
* Participate in Agile ceremonies including sprint planning, backlog refinement, daily standups, and retrospectives.
* Participate in peer code reviews and mentor junior developers through constructive feedback.
* Help establish engineering standards, reusable patterns, and best practices across development teams.

**Quality &amp; DevOps**
* Develop automated unit, integration, and end-to-end tests.
* Support CI/CD pipelines and automated deployment processes.
* Troubleshoot production issues and participate in root cause analysis.
* Contribute to application performance optimization, monitoring, and operational excellence.
